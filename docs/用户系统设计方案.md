# 用户系统设计方案

## 一、技术选型

### 推荐方案：Supabase（免费）

| 对比项 | Supabase | Vercel KV | 自建数据库 |
|--------|----------|-----------|-----------|
| **数据库** | PostgreSQL（完整SQL） | Redis（KV存储） | 需自己运维 |
| **认证** | 内置（邮箱/手机/微信） | 无，需自建 | 需自建 |
| **免费额度** | 500MB数据库 + 5万MAU | 有限 | 服务器费用 |
| **实时订阅** | ✅ 内置 | ❌ | 需自建 |
| **适合阶段** | MVP到生产 | 简单缓存 | 大规模 |

**结论：Supabase 最适合当前阶段** — 免费、自带认证和数据库、5分钟集成。

├── ai_companion_exp (AI伙伴经验值)

exercise_records（运动记录）
├── id (uuid)

mood_records（心情记录）
├── id (uuid)
├── user_id

├── recorded_at

├── has_weight_record (有体重记录)
├── has_exercise_record (有运动记录)
├── has_mood_record (有心情记录)
├── streak_days (连续打卡天数)
└── created_at

## 三、认证流程

### 3.1 注册/登录方式

| 方式 | 优先级 | 说明 |
|------|--------|------|
| **手机号 + 验证码** | ⭐ 最高 | 中国用户习惯，Supabase支持 |
| **邮箱 + 密码** | 备选 | 国际用户或邮箱偏好者 |
| **微信登录** | Phase 2 | 需要微信开放平台审核 |

### 3.2 注册流程

```
用户打开App
    ↓
输入手机号
    ↓
获取短信验证码（6位）
    ↓
验证通过 → 自动创建账号
    ↓
引导填写基础信息（昵称/身高/体重/目标）
    ↓
创建AI伙伴 → 开始对话
```

### 3.3 新用户引导（Onboarding）

```
Step 1: "嗨！我是小绿 🌱 想成为你的减脂伙伴~"
        → 输入昵称

Step 2: "告诉我你的身体数据，这样我能更好地帮你~"
        → 性别 / 身高 / 体重 / 年龄

Step 3: "你的目标是什么？"
        → 减脂 / 维持 / 增肌
        → 目标体重

Step 4: "你平时的运动习惯是？"
        → 久坐 / 轻度 / 中度 / 高强度

Step 5: "太好了！我们开始吧~ 🎉"
        → 创建AI伙伴，进入对话
```

## 五、API设计

### 5.1 认证API（Supabase内置）

```
POST /auth/v1/signup          → 注册
POST /auth/v1/token?grant_type=password  → 登录
POST /auth/v1/otp             → 发送验证码
POST /auth/v1/verify          → 验证码登录
POST /auth/v1/logout          → 登出
GET  /auth/v1/user            → 获取当前用户
```

### 5.2 业务API（Vercel Serverless）

```
# 用户资料
GET    /api/profile           → 获取个人资料
PUT    /api/profile           → 更新个人资料

# 对话
GET    /api/conversations     → 对话列表
POST   /api/conversations     → 创建对话
GET    /api/conversations/:id/messages  → 消息历史
POST   /api/chat              → 发送消息（已有）

# 健康数据
GET    /api/weights           → 体重记录列表
POST   /api/weights           → 记录体重
GET    /api/diet              → 饮食记录列表
POST   /api/diet              → 记录饮食
GET    /api/exercises         → 运动记录列表
POST   /api/exercises         → 记录运动
GET    /api/moods             → 心情记录列表
POST   /api/moods             → 记录心情

# 统计
GET    /api/stats/daily       → 今日统计
GET    /api/stats/weekly      → 本周报告
GET    /api/stats/trends      → 趋势数据

# 成就
GET    /api/achievements      → 成就列表
POST   /api/achievements/check → 检查新成就

# 养成
GET    /api/companion         → AI伙伴状态
POST   /api/companion/exp     → 增加经验值
```
